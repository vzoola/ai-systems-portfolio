Every fact flows left → right: a local model reads the raw sources, the memory core checks and dates it, the gate lets only current truth through, then any model — owned or third-party — reaches it through a file, a serve API/MCP call, or context injection, and the products serve it. The faint lines are the full web; click to isolate any one piece.

Born from a real bug — a stale $12.69 balance nearly overwrote the true $30. That one incident is why every fact here is dated, quoted, and gated before any agent or product can state it. Governed, human-supervised, and built to keep tomorrow's answers from reaching back to yesterday's facts.

Guarantees are strongest where the loop is owned; third-party AIs get fed verified truth through connectors — a floor raised, not a promise outsourced.
